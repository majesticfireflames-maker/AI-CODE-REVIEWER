AI Code Reviewer

AI-powered code review tool that analyzes code for bugs, performance issues, security vulnerabilities, and provides improved code suggestions.

 Features

- Bug Detection - Find syntax and logic errors
- Performance Optimization - Get speed improvement suggestions
- Security Analysis - Identify vulnerabilities
- Code Explanation - Understand what the code does
- Improvement Suggestions - Get code quality tips
- Improved Code - See the fixed version

 Tech Stack

- Backend: FastAPI, Python
- AI: Groq API (Llama 3.3 70B)
- Frontend: HTML, CSS, JavaScript

 Quick Start

```bash
pip install -r requirements.txt
python app.py
